# 🐍 Snake Game

A classic and fun **Snake Game** built with **JavaScript** and **Tailwind CSS**.

The game is fully **responsive**, so you can enjoy playing it on both **desktop/laptop** and **mobile devices**.

## 🎮 Features

* 🐍 Classic Snake gameplay
* 📱 Fully responsive design
* 💻 Playable on both mobile and desktop/laptop
* ⏸️ Stop the game anytime
* ▶️ Resume the game
* 🔄 Restart the game
* 🎨 Modern and responsive UI
* ⚡ Built with Vanilla JavaScript
* 💨 Styled with Tailwind CSS

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

## 📱 Responsive Design

The game is designed to work smoothly on different screen sizes, including:

* 📱 Mobile
* 📱 Tablet
* 💻 Laptop
* 🖥️ Desktop

